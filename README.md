# Thumbmatic

AI-powered realtime thumbnail generation platform.

## Tech Stack

### Frontend
- React
- TailwindCSS
- Vite
- SSE Streaming

### Backend
- FastAPI
- SQLModel
- ImageKit
- OpenAI

---

## Setup

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```
